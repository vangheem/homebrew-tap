# vangheem/homebrew-tap

Homebrew formulae for [vangheem](https://github.com/vangheem)'s tools.

```sh
brew install vangheem/tap/gitsnack
```

| Formula | Description |
| --- | --- |
| [gitsnack](https://github.com/vangheem/gitsnack) | Native GitHub pull request review app with opencode agent sessions |

Formulae are updated automatically by each project's release workflow.
